# Tito - Universal Ticket Booking Platform

Tito is a comprehensive ticketing and reservation platform designed to help businesses across multiple industries manage bookings efficiently. Whether you're running a bus service, hotel, cinema, airline, event venue, or restaurant, Tito provides the tools you need to sell tickets and manage reservations seamlessly.

## 🎯 What is Tito?

Tito is an all-in-one booking platform that supports:
- **🚌 Bus Tickets** - Real-time seat management and route bookings
- **🏨 Hotel Reservations** - Multi-property reservation system with occupancy management
- **🎬 Cinema Tickets** - Theatre management with visual seat selection
- **✈️ Flight Bookings** - Comprehensive airline booking system
- **🎪 Event Tickets** - Event management and ticketing platform
- **🍽️ Restaurant Reservations** - Table booking and reservation management

## 📚 Getting Started with Development

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/tito.git
cd tito

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the site.

### Building for Production

```bash
npm run build
npm run start
```
